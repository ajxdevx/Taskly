# Actor Portals and Permissions

| Actor | Primary capabilities |
|---|---|
| Super Admin | Platform administration, users, all projects, audit evidence |
| Organization Admin | Organization users, project governance, audit evidence |
| Project Manager | Projects, sprints, task creation, assignment, status management |
| Team Lead | Sprint planning, delivery coordination, task management |
| Developer | Assigned work, status updates, comments and time tracking |
| Designer | Design work, status updates, comments and time tracking |
| QA Engineer | Quality tasks, defects, review workflow and time tracking |
| Client | Read-only portfolio visibility and collaboration comments |
| Auditor | Read-only delivery visibility and audit-log access |
