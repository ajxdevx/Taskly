# API Modules

- `/api/auth`: login and authenticated identity
- `/api/workspaces`: organization workspaces
- `/api/users`: actor directory and controlled user creation
- `/api/projects`: portfolio and project creation
- `/api/sprints`: sprint capacity and progress
- `/api/tasks`: filtering, creation, details, updates and workflow transitions
- `/api/tasks/{id}/comments`: collaboration feed
- `/api/tasks/{id}/time`: worklog tracking
- `/api/dashboard/summary`: portfolio command-centre aggregation
- `/api/analytics`: project delivery scorecards
- `/api/notifications`: personal operational alerts
- `/api/audit-logs`: privileged governance evidence
